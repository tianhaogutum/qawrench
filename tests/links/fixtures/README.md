`markdown-containers/` establishes the container contract with separate nested
inline and repeated-reference fixtures. `expected.json` contains hand-authored

are global to the document and never occurrences. Each source also has a report

Supported containers use `>`, `-`, `+`, `*`, or 1–9 digit ordered markers ending
in `.` or `)`, with spaces for indentation. They may nest; list continuation
lines with explicit indentation supply the item's content indentation; ordinary
paragraph prose can also continue lazily. Blank lines separate paragraphs.
Negative contracts: tab indentation is unsupported;
container code fences/indented code, code spans,
images, comments, HTML, and thematic breaks must not create occurrences or
reference definitions. Container changes end code spans and block exclusions;
definitions cannot interrupt a paragraph. CRLF does not change the coordinates.
